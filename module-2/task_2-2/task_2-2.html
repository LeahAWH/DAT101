1. Where should you use constants, and where should you use variables? Can they all be constants?

    2. Constants should be used for values that do not change during the execution of the program, while variables should be used for values that may change. Therefore not all values can be constants.

  2. How do parentheses affect the arithmetic outcome of an expression?

    3. Parentheses affect the order of operations in an expression, ensuring that the operations within the parentheses are performed first, before any other operations outside of the parentheses.

  3. How do we limit floating-point numbers to a given number of decimals?

    4. We can limit floating-point numbers to a given number of decimals by using methods such as toFixed(), or by rounding the number to the desired decimal places using mathematical operations.

  4. How can we compare two floating-point values to see if they are equal (is 12.199999 the same as 12.2)?

    5. We can compare two floating-point values by checking if the absolute difference between them is less than a small threshold value (epsilon), which accounts for potential precision errors in floating-point representation.

  5. What do comparison operators return, and how can we check if they are FALSE or TRUE?

    6. Comparison operators return boolean values (TRUE or FALSE). We can check if they are FALSE or TRUE by using conditional statements (if-else), or by evaluating the boolean value in expressions.

  6. How does the Math.random() function work, and what can it be used for?

    7. Math.random() generates a pseudo-random floating-point number between 0 (inclusive) and 1 (exclusive). It can for example be used to generate random numbers for games, simulations, or random sampling.

  7. What is modulus (%), and when do we need this operator in mathematical operations?

    8. The modulus operator (%) returns the remainder of a division operation. We need this operator when we want to find the remainder after dividing one number by another.
